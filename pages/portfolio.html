How to Add a New Project

1. Add your project image to assets/images/portfolio/
2. Open pages/portfolio.html
3. Remove the empty state block above
4. Uncomment the .portfolio-grid section
5. Duplicate the card template, update the image, title, category badge, and description
6. Save — your new card will appear automatically in the grid.
