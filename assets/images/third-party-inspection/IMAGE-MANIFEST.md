# Image Manifest — Third-Party Inspection Knowledge Images

This folder holds images used by the Third-Party Inspection Knowledge pages
(`services/third-party-inspection/*.html`). Existing site images elsewhere
(e.g. `assets/images/services/third-party-inspection.jpg`) are NOT part of
this folder and were not touched.

Every image below is currently an **original placeholder illustration**
(SVG, drawn from scratch), so there is zero copyright risk while the site
is in this stage. Replace each file with a real, license-safe photo at the
same path/filename (same aspect ratio) and the layout will not break — the
container (`.kb-image-frame` / `.service-hero-banner`) is fixed-aspect-ratio
and uses `object-fit: cover` or CSS `background-image`, so it accepts any
image of the same ratio.

## Replacement steps (per image)
1. Prepare the real photo at (or close to) the aspect ratio above.
2. Compress to WebP/AVIF, keep file size small (mobile-friendly).
3. Save using the same filename in this folder (swap `.svg` for `.webp`/`.jpg`)
   and update the one `src=`/`background-image:` line in the HTML.
4. Update the `alt` text to describe the real photo accurately.
5. If the photo's source names a specific fabric/material, use that exact
   name in the filename (do not guess fabric names).

## Not covered by this manifest

are written directly in the HTML — decorative icons, not photos.

## Defect Encyclopedia icons (defect-icons/ subfolder)
26 small original SVG diagram icons, one per defect entry on garment-defects-encyclopedia.html
(70x70 display size). Each is a simple swatch-based diagram, not a photo — these are meant to
stay as diagrams even after real photos are added elsewhere, since they illustrate an abstract
defect pattern rather than a specific real garment. Filenames match the defect name in kebab-case
(e.g. "Loose Button" -> loose-button.svg), located in defect-icons/.
